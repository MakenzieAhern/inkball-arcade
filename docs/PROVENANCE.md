# Provenance

This portfolio edition was prepared from the local Inkball coursework project supplied by Yuchen Deng. Yuchen Deng confirmed that he independently wrote the original game code. This authorship statement does not extend to any course-provided template or bundled artwork. The original folder was left unchanged; development and verification took place in a separate working copy.

The supplied project contained five production Java classes, three level layouts, a JSON configuration, Processing sprite assets, tests, and a Gradle wrapper. It had no Git history, README, project license, or recorded attribution for its sprites. The public repository therefore starts with a curated snapshot rather than reconstructed commit history.

## Publication preparation

- Excluded IDE settings, Gradle caches, compiled build outputs, and operating-system metadata.
- Used a functional repository name, `inkball-arcade`.
- Re-tested the source, corrected gameplay/build issues, and documented the resulting verification separately.
- Preserved the supplied game assets and level design. No claim is made that the portfolio maintainer created every bundled image or any course-provided template.
